## 3. 왜 크리에이티브 웹 개발인가? [#3-why-creative-web-dev]

**소프트웨어 엔지니어링의 현재**

- 모델 성능은 선형으로 늘지 않는다. 두 배씩 는다.

- 이게 크리에이티브 소프트웨어 실천에 뜻하는 것
  - 코드를 쓰는 게 더 이상 병목이 아니다. 뭘 원하는지 아는 게 병목이다
  - **상상력이 가장 큰 병목이다.**
  - '소프트웨어'는 비쌌다. 팀, 몇 달, 예산. 지금은 프롬프트 하나, 오후 한나절, 노트북 한 대
  - 누구나 소프트웨어를 만들 수 있다. 모두가 만들 것이다

- 2020년대: 같은 일이 소프트웨어에 일어나고 있다
  - AI가 소프트웨어를 빠르게 복제 가능하게 만들었다. '만드는' 기술이 더 이상 관문이 아니다
  - 이건 소프트웨어를 쓰는 예술적 표현을 해방시킨다. '먼저 만들 줄 알아야 한다'는 제약이 사라졌다
  - 소프트웨어 만들기가 이제 그림 그리기보다 쉽다. 아마 훨씬 쉽다
  - 역설적으로, 그래서 소프트웨어를 이용한 예술적 실험이 폭발할 것이다. 싼 매체 → 거친 실험. 사진 → 현대미술과 똑같이
- 굉장히 중요하고, 굉장히 흥미로운 시대
  - 우리는 같은 규모의 또 다른 혁명을 목도하고 있다. 엄청난 가능성, 그리고 동시에 기존의 많은 관행이 사라질 것이다

**단서: AI는 통계적 기계다**

- AI는 평균으로 회귀한다. 언제나
  - 모델은 통계적 기계다. 가장 그럴듯한 다음 것을 예측한다
  - [확률적 앵무새 (Stochastic Parrot)](https://en.wikipedia.org/wiki/Stochastic_parrot) (Bender 외, 2021): 학습 데이터의 패턴을, 그럴듯하게, 의미 없이 반복한다
  - 창작 과정을 통째로 맡기면 결과는 평균으로 수렴한다. '어디서 본 것 같은데', 전혀 새롭지 않은

**코딩 에이전트**

- 코딩 에이전트 = 모델 + 도구. 네 파일을 읽고, 고치고, 명령을 실행하고, 에러를 읽고, 다시 시도한다. 네가 설명하면 만들고, 네가 검토한다
- 에이전트 = 모델 + 도구 + 루프. 모델이 다음 단계를 정하고, 도구가 실행하고(파일 읽기, 파일 고치기, `pnpm dev` 실행, 스크린샷), 결과가 모델로 돌아가고, 반복. 모든 단계가 네게 보이고 멈출 수 있다
- 기억은 이 대화의 컨텍스트 윈도우다. 네 프로젝트에 대해 아는 건 이번 세션에 읽은 것, 그리고 `AGENTS.md`(아래)가 전부다
- 권한: 명령을 실행하거나 프로젝트 밖 파일을 건드리기 전에 물어본다. 명령을 읽어라. 말이 되면 승인. "Allow all"은 나중에
- [Codex](https://chatgpt.com/codex) (OpenAI): <Term id="cli">CLI</Term>, VS Code 확장, 클라우드. ChatGPT 요금제에 포함. GPT-6 Astra / GPT-6.1 Sol 사용
- <Term id="claudeCode" /> (Anthropic): 터미널, VS Code 확장, 데스크톱 앱, 웹. Claude 구독 필요. Claude Opus 5.5 / Fable 5.1 사용
- [Cursor AI](https://cursor.com/), [GitHub Copilot](https://github.com/features/copilot), [Gemini CLI](https://github.com/google-gemini/gemini-cli): AI 통합 에디터와 다른 CLI들. 같은 아이디어, 다른 회사
- **우리는 VS Code + Claude Code**를 쓴다. 모델은 Claude Opus 5.5

**기본 셋업: VS Code + Claude Code**

1. <Term id="vscode" /> 설치: https://code.visualstudio.com/Download
2. Claude Code (<Term id="cli">CLI</Term>) 설치. 터미널을 열고 실행
   - macOS: `curl -fsSL https://claude.ai/install.sh | bash`
   - Windows PowerShell: `irm https://claude.ai/install.ps1 | iex`
   - 새 터미널을 열고 `claude --version` 입력. 버전 번호가 나오면 성공
3. VS Code에 Claude Code 확장 설치
   - 확장 탭 열기: `Cmd+Shift+X` (Mac) / `Ctrl+Shift+X` (Windows)
   - "Claude Code" 검색 (제작: Anthropic) → Install
   - 커맨드 팔레트 (`Cmd+Shift+P` / `Ctrl+Shift+P`)에서 "Claude Code" 입력 → **Open in New Tab**
4. Chrome에 [Claude in Chrome](https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn) 확장 설치 (Brave, Edge, Arc도 됨). Claude Code와 같은 계정으로 로그인
5. VS Code에서 프로젝트 폴더를 열고, 터미널을 열고 (`` Ctrl+` ``), `claude` 입력
6. 수업용 계정으로 로그인 (아래)
7. `/model` 입력 후 **Claude Opus 5.5** 선택
8. `/chrome` 입력 후 **Enabled by default** 켜기. 상태에 "Extension: Installed"가 보여야 한다

- 믿기 전에 뭘 바꿨는지 읽어라: `git diff`. 버리려면 `git restore .`, 남기려면 `git commit`
- 한 번에 한 가지. 작은 단계로, 매번 브라우저에서 확인
- 레포의 `AGENTS.md`가 에이전트에게 이 프로젝트의 규칙을 알려준다. 자세한 건 W1에서

**<Term id="harness">하네스</Term> 엔지니어링**

- 모델은 모두에게 같다. *네 프로젝트에서* 에이전트를 잘 돌게 하는 건 모델 주변의 모든 것, **하네스**다
- 하네스란: 처음에 읽는 규칙(<Term id="agentsMd" />), 안내받는 가이드(`docs/`), 남기고 가는 기억(실험마다 `README.md` 하나), 통과해야 하는 검사(`pnpm typecheck`, `pnpm build`, 브라우저에서 라우트 열기), 저장하는 체크포인트(되면 `git commit`)
- 하네스가 없으면 에이전트는 추측한다: 엉뚱한 폴더, 시키지도 않은 Tailwind, 2023년의 Pages Router, 페이지를 열어보지도 않고 "됩니다". 있으면 매번 같은 일을 같은 방식으로 한다
- 2026년 10월 현재: `AGENTS.md`가 회사를 가로지르는 표준이다 (Codex, Claude Code, Cursor, Gemini 전부 읽는다; [agents.md](https://agents.md/)). Next.js는 자기 블록을 거기에 써넣는다. 그 위에: 훅(수정할 때마다 타입체크), 스킬(재사용 절차), MCP(브라우저 같은 도구). 이제 프롬프트보다 하네스가 더 큰 레버다
- 이 템플릿에는 하네스가 들어 있다. `AGENTS.md`와 `docs/`를 한 번 읽어라. 에이전트는 매 세션 읽는다. 같은 실수를 반복하면 프롬프트가 아니라 하네스를 고쳐라

**브라우저 도구: Claude in Chrome**

- 에이전트는 코드를 쓴다. 브라우저가 없으면 네 페이지를 볼 수 없다. 확장(셋업 4번과 8번)이 있으면 직접 Chrome을 연다: http://localhost:3000 로 가고, 스크린샷을 찍고, 콘솔 에러를 읽고, 클릭하고, 입력하고, 스크롤한다
- 이게 루프를 닫는다: 고치기 → 라우트 열기 → 보기 → 콘솔 읽기 → 고치기 → 다시 보기. 없으면 에이전트는 "될 겁니다"라고 한다. 있으면 확인한다
- 이렇게 시켜라: "localhost:3000/experiments/w1/time-interval 열고, 콘솔 에러 확인하고, 뭐가 보이는지 말해줘". 고친 다음엔: "페이지 열어서 원이 마우스를 따라오는지 확인해"
- 눈에 보이는 Chrome 창에서 돈다. 클릭 하나하나 네가 본다. 로그인된 사이트도 보이니까, 신경 쓰이면 수업용 Chrome 프로필을 따로 만들어라
- VS Code 채팅 패널에서는 `@browser`를 치면 브라우저를 넘긴다. 터미널에서는 `/chrome`이 상태를 보여주고, 끊기면 다시 연결한다
- 문서: [Claude Code with Chrome](https://code.claude.com/docs/en/chrome)

Chrome 셋업은 W1 1절에서 같이 한다.
